# FluxoGen legal

Public privacy policies and terms for FluxoGen apps, served with GitHub Pages.

One folder per project, each with `privacy/index.html` and `terms/index.html`.

**Theming:** each app can match its own product. `assets/legal.css` is the default (used by Velvet Arcana); `assets/ease.css` is the Ease theme (warm paper, clay accent, Manrope, light and dark, mirroring the tokens in FluxoGen/ease `src/index.css`). A new app either reuses `legal.css` or adds `assets/<app>.css` and links it from its two pages. Fonts live in `assets/fonts/` (Manrope is SIL OFL 1.1, licence included).

**Public repo: only publishable legal pages go here. No drafts with internal notes, no customer or health data, no secrets.**
